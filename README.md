## Recent Projects

### Intake Engine v1.0

A modular Python CLI ingestion tool for turning messy CSV / TSV / Excel files into analytics-ready outputs.

Features include:

- Automated cleaning and normalization
- Validation and profiling reports
- DuckDB loading
- Batch processing
- YAML pipeline configs
- HTML quality reporting

### Metrics Engine v1.0

A config-driven KPI calculation engine that turns cleaned data into validated, reusable metric outputs for Power BI, Excel, and future AI analytics workflows.

Features include:

- Schema-driven column normalization
- YAML-based metric definitions
- Validation before calculation
- Configurable segment rollups
- Sum-before-divide KPI logic
- Long and wide metric outputs
- Metric dictionary generation
- Validation report export
- CLI workflow with test coverage
